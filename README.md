# JJ揭棋助手

JJ象棋揭棋模式的自动辅助 Android 应用：无障碍服务读取棋局、Pikafish 引擎算出走法、模拟点击自动落子，悬浮窗显示局面统计和前三个候选走法。

## 下载安装

从本仓库 **Releases** 下载最新 APK 安装（arm64 设备）。应用本身无网络权限。

## 首次运行授权顺序

1. 打开应用 → 点「前往开启」→ 系统设置中开启本应用的无障碍服务
2. 返回应用 → 点「授权悬浮窗」→ 允许显示在其他应用上层
3. 点「授权通知」→ 允许通知（Android 13+）
4. 点「开始校准」→ 打开JJ象棋揭棋对局在前台 → 回到校准页自动截图 → 自动检测边界 → 拖动9×10点阵微调 → 点「识别预览」核对（红点为异常）→ 保存
5. 打开JJ象棋，进入揭棋对局
6. 回到应用点「启动辅助」，在悬浮窗中开启「自动辅助」开关；如需自动走棋再开「自动落子」

> 悬浮窗只有「自动辅助」「自动落子」两个开关，无手动刷新按钮。关闭自动落子时只显示建议走法，由你手动走。

## 功能分层

1. **屏幕获取**：无障碍 `takeScreenshot`（API 30+）为主，节点读取优先，前台服务常驻通知
2. **实时触发**：帧差检测，画面稳定后识别，识别中变化则中断重来
3. **棋盘识别**：9×10 交叉点逐点判断有子/红黑/明暗/棋字，模板可为空
4. **悬浮窗**：可拖动、可折叠、白字黑边、不抢焦点
5. **局面核心**：9×10 棋盘 + 暗子池，翻子吃子扣减，冲突提示重校准
6. **引擎**：Pikafish UCI，多次随机分配暗子生成全明 FEN，汇总前三，三档算力，引擎缺失降级为统计模式
7. **自动落子**：`dispatchGesture` 模拟点击起点/终点，失败重试后切手动
8. **手动摆盘**：9×10 点阵逐点设置红黑/明暗/棋字

## 需要按真实截图调参的阈值

所有阈值集中在 `app/src/main/java/com/jjchess/helper/core/Constants.kt`，按用途分组并注明含义：

| 分组 | 常量前缀 | 含义 | 调整方向 |
|------|----------|------|----------|
| 棋盘几何 | `BOARD_*_RATIO` | 交叉点默认坐标（比例），来自 1264×2780 截图 | 校准不准时优先用校准界面拖动，或改这里 |
| 棋子尺寸 | `PIECE_*_RATIO`、`PIECE_OCCUPIED_MIN_GOLD` | 半径、有子判定的金橙占比下限 | 漏判有子则调低 `PIECE_OCCUPIED_MIN_GOLD` |
| 颜色 | `GOLD_*`、`BOARD_BG_*`、`RED_TEXT_*`、`BLACK_TEXT_*` | 金橙棋子/背景/红黑字的 RGB 阈值 | 换机型/皮肤后按实际采样微调 |
| 明暗 | `OPEN_GOLD_RATIO_MAX`、`OPEN_TEXT_RATIO_MIN` | 明子/暗子区分 | 明暗判错时调整 |
| 红黑 | `SIDE_RED_RB_DIFF_MIN`、`SIDE_RED_BRIGHT_MIN` | 红黑方判定 | 红黑判错时调整 |
| 模板 | `TEMPLATE_MATCH_THRESHOLD` | 棋字模板匹配相似度 | 误匹配则调高 |
| 触发 | `CAPTURE_*`、`MAX_RECOGNIZE_RETRIES` | 稳定时长、帧差阈值、重试次数 | 识别频繁打断则调高稳定时长/帧差阈值 |
| 落子 | `MOVE_*` | 点击延时、重试 | 点击无响应则调大 `MOVE_TAP_GAP_MS` |
| 引擎 | `ENGINE_*` | 算力、采样次数、超时 | 卡顿则降 nodes，弱则升 |
| 悬浮窗 | `OVERLAY_*` | 文字大小、默认位置 | 遮挡棋盘则改 `OVERLAY_DEFAULT_Y_RATIO` |

默认几何参数取自开局截图：列中心 x≈[92,227,...,1175]（列距135px），行中心 y≈[804,...,1992]（行距132px），图幅1264×2780。

## 引擎

Pikafish arm64 二进制由 GitHub Actions 在构建时从官方 Release 下载并打包进 `assets/engine/pikafish`，不提交进仓库。若获取失败或启动失败，应用自动降级为纯统计模式（基于走法生成器的启发式评分），不崩溃。

push 到 main/master 或手动触发 workflow 即自动编译并发布 APK 到 Releases。
